# LLM 在飞行器制导控制领域应用 — 调研清单

## A. 定位类
- [x] 1. 学界怎么定义 LLM 在制导控制中的应用？主流分层是什么？与传统算法是替代还是互补、边界在哪？
  - 结论：无统一定义；主流表述为「LLM 作为高层认知智能体，负责语义理解、任务规划与决策，经结构化接口与底层交互，不直接输出控制量」（PCA 视角：认知层）。主流分层（按回路位置）：L1 任务规划 / L2 决策行为 / L3 参数调参 / L4 直接控制（极少）/ L5 辅助。主流共识为互补而非替代；边界画在三条线：频率（LLM 低频 vs 传统高频）、可验证性（LLM 输出必过确定性校验/安全过滤器）、职责（语义柔性 vs 几何最优与稳定性）
  - 文献：Tian et al. PCA 综述（MDPI Drones）；Multifaceted Survey（arXiv 2602.19534）；PEACE（arXiv 2606.00104）；Say'n'Fly LLM-Modulo；RB-LLM Control（SDU）；UAV Projects 实证研究（arXiv 2509.12795）
